Project overview:
Assigned by Lexicon School, this project involved creating a website for purchasing online movie copies. <br/>
Teams of three students worked together from November 15 to November 25.<br/> Features included user information storage, navigation, an admin page, and movie details.<br/>
Technologies Used:<br/>
Back-End: C#, Ajax, LinQ<br/>
Front-End: HTML, CSS, Bootstrap, JavaScript (jQuery)<br/>
